# Source index

One row per source. Each row links to its note in `notes/`, which quotes the rules with section links. Raw copies of web pages are in `vendor/pages/<track>/` (gitignored; re-fetch with `defuddle parse <url> --md`).

**Kind**: *normative* = binding on some audience (a project's own rules); *community advice* = recommendations with no enforcement; *descriptive* = describes practice or semantics without prescribing.

**Licences** matter because the guide will quote and adapt. Summary of the constraints, from the rows below:

- Quote and adapt with attribution: Apache-2.0 (Lean core, Batteries, Mathlib code, Lean Reference, TPIL, Verso, doc-gen4, CSLib, Iris-Lean, cpdt-lean, metaprogramming book, Plausible), MIT (Mathlib website docs, agda-stdlib, Dafny, ocamlformat, Jane Street Base, leanfmt, metaprogramming cookbook, LSpec), CC BY 4.0 (FPIL text, F# docs, Iris docs), CC BY 3.0 (bbatsov Ruby and Clojure, Effective Scala, Google's Haskell guide), Apache-2.0 OR MIT (Rust guides), BSD-3 (hlint, ormolu, fourmolu, elm-format, Haskell `base`), public domain (PEP 8), CC0 (Idris 2 docs).
- Share-alike: ocaml.org guidelines (CC BY-SA 4.0); adapted text would have to be CC BY-SA. Kowainik's source repo is MPL-2.0 (file-level copyleft). Rocq stdlib LGPL-2.1, MathComp CeCILL-B (code licences; short quotes only).
- Non-commercial, paraphrase only: Databricks Scala guide (CC BY-NC-SA 4.0), PureScript guide (CC BY-NC-SA 3.0).
- No licence found (default copyright, short quotes with citation only): lean-lang.org pages and FRO blog, the Zulip archive, Tibell's Haskell guide, Cornell CS 3110, the F* and CoqStyle wikis, the Minsky/King/Noonan/Wlaschin essays, lean4.dev. Brady's book is commercial.
